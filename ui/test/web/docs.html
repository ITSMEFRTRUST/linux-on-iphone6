Span (lv_spangroup)

A spangroup is an object used to display rich text. Unlike a lv_label, it can show text with different fonts, colors and sizes in one object.

Overview

Spans are added with lv_spangroup_add_span() and styled through lv_span_get_style(). Call lv_spangroup_refresh() once you are done.

Modes

LV_SPAN_MODE_FIXED
Fixed object size.
LV_SPAN_MODE_EXPAND
Expand the object size to the text size but stay on a single line.
LV_SPAN_MODE_BREAK
Keep the width, break lines that are too long and auto-expand height.

Example

lv_obj_t *sg = lv_spangroup_create(lv_screen_active());
lv_span_t *s = lv_spangroup_add_span(sg);
lv_span_set_text(s, "Hello, world");
lv_spangroup_refresh(sg);

Note: a very long span in BREAK mode is laid out on every refresh; keep paragraphs short on slow CPUs.

API

FunctionDescription
lv_spangroup_createCreate a spangroup object.
lv_spangroup_add_spanAdd a new span.
lv_spangroup_set_modeSet the mode of the spangroup.
