### Nerd Fonts icon glyphs

Nerd Fonts adds icon glyphs from several sets (for example Font Awesome,
Material Design Icons, Codicons, Octicons, Powerline symbols), each under its
own licence: mostly MIT, OFL-1.1, CC-BY-4.0 or Apache-2.0. The licence text and
copyright notice of every glyph set (Nerd Fonts, Codicons, Devicons, Hack extra
glyphs, Font Awesome, Font Awesome Extension, Material Design Icons + the full
Apache-2.0 text, Octicons, Seti-UI, Pomicons, Powerline Extra, Powerline
Symbols, IEC Power Symbols, Weather Icons, Font Logos) ships verbatim in
`ui/assets/JBMonoNF-GLYPH-LICENSES.txt`. Summary: Nerd Fonts' licence audit,
<https://github.com/ryanoasis/nerd-fonts/blob/master/license-audit.md>.

### English word list (wordfreq, CC BY-SA 4.0)

`ui/assets/words-en.txt` is generated by `ui/assets/words-en-gen.py` from
**wordfreq** 3.1.1 by Robyn Speer (<https://github.com/rspeer/wordfreq>).
wordfreq's code is Apache-2.0; its word-frequency data is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The word list
is a derived work of that data (the most frequent English words, filtered and
reordered by the script) and is shared under **CC BY-SA 4.0** as well.
Attribution: *word frequencies from wordfreq by Robyn Speer, CC BY-SA 4.0;
wordfreq in turn builds on several sources, credited in its README.*

`ui/assets/words-shell.txt` (shell command names for the Terminal's
suggestions) is part of this project.

App icons in `ui/assets/icons/` are original designs generated by
`ui/assets/icons/gen.py` (GPL-3.0-or-later with the rest of `ui/`).

## Fetched by `ui/fetch-deps.sh` (not bundled)

`ui/fetch-deps.sh` downloads these into `ui/third_party/` (gitignored) and
`var/` (gitignored). None of them is stored in this repository.

| Component | Licence | Notes |
|---|---|---|
| LVGL 9.6.0 (`ui/third_party/lvgl/`) | MIT | `LICENCE.txt` in the clone; LVGL's bundled sub-libraries carry their own notices under `src/libs/`. Compiled into Orchard. |
| libvterm 0.3.3 (`ui/third_party/libvterm-0.3.3/`) | MIT | `LICENSE` in the tarball. Compiled into Orchard (Terminal). |
| musl libc (Alpine `musl-dev`, in `var/sysroot`) | MIT | Orchard's phone build is statically linked against it. |
| LLVM compiler-rt builtins (Alpine `compiler-rt`) | Apache-2.0 WITH LLVM-exception | Runtime library linked statically. |
| Linux UAPI headers (Alpine `linux-headers`) | GPL-2.0-only WITH Linux-syscall-note | Headers only. |
| libjpeg-turbo (Alpine `libjpeg-turbo-static`, in `var/jpeg`) | IJG + BSD-3-Clause + zlib | Camera JPEG encoder; linked only if present. |

When you distribute a built Orchard binary, ship the notices of LVGL,
libvterm, musl, compiler-rt and libjpeg-turbo with it.

## Put into the boot image by the build scripts (not in this repository)

`bin/mkblob` and the `bin/mk*` helpers build the image from upstream software
that you download or build yourself (Alpine aarch64 packages for the
userspace bundles). None of it is stored here.

| Component | Licence |
|---|---|
| Linux kernel (Hoolock Linux) | GPL-2.0-only (with syscall note) |
| m1n1 | MIT (plus the licences of its bundled parts) |
| HoolockRD initramfs (busybox and others) | GPL-2.0 and others, see HoolockRD |
| BlueZ, BlueALSA, D-Bus (`bin/mkbt`) | GPL-2.0 / LGPL-2.1, MIT, AFL-2.1 / GPL-2.0 |
| iw, wpa_supplicant, wireless-regdb (`bin/mkwifi`) | ISC, BSD-3-Clause, ISC |
| ssl_client, CA bundle, nftables, readline, ncurses (`bin/mknet`) | GPL-2.0 (busybox), MPL-2.0 (CA data), GPL-2.0, GPL-3.0, MIT-style |
| curl, built against OpenSSL and zlib (`bin/mkcurl`) | curl licence (MIT-style), Apache-2.0, zlib |
| e2fsprogs, device-mapper (`bin/mkdisk`) | GPL-2.0 / LGPL-2.0, LGPL-2.1 |
| alsa-utils / alsa-lib, mpg123 (`tools/alsa.tgz`) | GPL-2.0 / LGPL-2.1, LGPL-2.1 |
| Tailscale (optional; you install it yourself in `/data/tailscale`) | BSD-3-Clause |

The licence column is a summary; the packages' own licence files are what
count.

No Apple firmware is included or redistributed. Firmware that some drivers
need is extracted by each user from their own iOS image; it stays under
Apple's terms and must not be redistributed. See [DISCLAIMER.md](DISCLAIMER.md).
