# CS35L19 (iPhone 6 speaker amp) — iOS 12.5.5 `AppleCS35L19Amp` init/play sequence

Source: `re/dis/CS35L19.s` (kext text `0xfffffff00829fbb0..0xfffffff0082a38cc`), base-class accessors in kc.macho
(`0xfffffff0080204b0..`), DT `re/dtree.txt`, defaults `re/cs35l19-defaults.txt`. Static analysis only, nothing run on hw.
Confidence tags: **[H]** read directly from code, **[M]** read from code, semantics inferred, **[L]** guess.

## 0. How the kext talks to the chip
Every register access goes through virtual methods of the (shared, base-class) amp driver; vtable = `0xfffffff0075acbd0+0x10` **[H]**:

| vt off | impl VA | signature (my name) |
|---|---|---|
| +0xa68 | 0x…80204b0 | `writeReg(chan, reg, val, verify=0)` |
| +0xa70 | 0x…80212b4 | `writeAll(reg, val)` (all channels; n61 has 1) |
| +0xa78 | 0x…802085c | `readReg(chan, reg)` |
| +0xaa8 | 0x…8020f64 | `readRegs(chan, reg, buf, len)` |
| +0xac0 | 0x…802124c | `updateBits(chan, reg, mask, val)` |
| +0xac8 | 0x…80213d0 | `updateAll(reg, mask, val)` |
| +0xae0 | 0x…82a216c | `setReset(bool hold)`: calls DT `function-reset`, and on release applies the rev-B0 trim patch (sec 1.2) |

State machine `0x…82a065c` (cur state at `this+0x208`): 0 = off (chip held in reset), 1 = standby, 2 = playing.
Transitions: 0→1 `0x82a251c`, 0→2 `0x82a25d0`, 1→2 `0x82a271c`, 1→0 `0x82a29a8`, 2→0 `0x82a2a04`, 2→1 `0x82a2a60` **[H]**.
This phone is the "ext" route (`function-ext_active`, `function-ext_master` in DT): `8028818(this,"ext")` is true, so
the code takes the *non-master* branches **[M]**; I follow the 0→2 path (`0x82a25d0`) below. Sleeps: `0x7cf8040(ms)` (IOSleep, **[M]**),
and a 10 ms deadline wait (`0x76b0794(10,1000000)`+`0x76b041c`).

## 1. iOS register writes, in order

### 1.1 Probe (`0x…829fd44`, called once at start) **[H]**
- DT: `function-reset` (GPIO 49 = 0x31), `function-alive` (GPIO 48 = 0x30), `function-mclk_control` (absent on n61), `speaker-config` (20 B), `speaker-vbca` (absent),
  `at-scale` (absent in this DT dump → zeros), `speaker-rdc` (syscfg `SRdc`, 4 B), `speaker-calib` (syscfg `SpCl`, 12 B), `amp_offset` (absent → 0), `interrupts [47 1]` (GPIO 47).
- Per channel: `setReset(0)` (release), `readRegs(ch, 0x01, 3)`: accept only `[0]==0x35`, `[1]&0xf0==0xa0`; then
  `[1]&0xf==1 && [2]&0xf0==0x90` → "CS35L19"; `[1]&0xf==2 && [2]&0xf0==0x10` → "CS35L21"; else "CS35Lxx unknown". Then `setReset(1)` (back into reset). Chip here = 35 A1 90 = CS35L19.
- `0x82a04d4` (sanity check) only re-reads 0x01..0x03 and checks 0x35/0xAx.

### 1.2 Reset release + rev-B0 trim patch (`0x…82a216c`, arg 0) **[H]** (meaning of the trim regs unknown)
Reset GPIO released (49 high on n61, confirmed live), no explicit delay in this fn. Then per channel, `rev = readReg(0x05)`; if `rev >= 0xB0` (ours = 0xB0):

| # | reg | val | note |
|---|---|---|---|
| 1 | 0x00 | 0x99 | unlock test/trim page (same key as cs35l33_patch) |
| 2 | 0x45 | 0x3f | default 0x2d |
| 3 | 0x46 | cfg[0x10] = 0x05 | from `speaker-config` (or from `speaker-vbca` low 5 bits if that prop exists); default 0x11 |
| 4 | 0x51 | 0xff | default 0xb7 |
| 5 | 0x59 | 0x0a | default 0x08 |
| 6 | 0x6b | 0x20 | default 0x22 |
| 7 | 0x54 | cfg[0x12] = 0x04 (only if non-zero) | default 0x44 |
| 8 | 0x00 | 0x00 | lock |
Then (all revs, only if cfg[0x11] != 0): `0x00=0x99; 0x66=cfg[0x11]=0xd0 (default 0x90); 0x00=0x00`.
`setReset(1)` just drives the reset GPIO low (no register access).

### 1.3 Power-up 0→2 (`0x82a25d0`) — for the "ext" speaker **[H]** unless noted
1. `0x82a2ce8(2)`:
   - MCLK on: `0x82a2030(1)` asks the clock provider for MCLK = **12 000 000 Hz** (0xb71b00, checks `vt+0x7f8()==0xb71b00` else logs "no suitable codec clock found"; the amp then runs MCLKDIV2 → 6 MHz internal).
   - `setReset(0)` + trim patch (1.2).
   - alive watchdog off `0x82a13e4(0)`: `0x0a[3:0] = 8` (mask 0x0f), `0x0c[3] = 1` (mask 0x08). (arg 1 would be `0x0a[3:0]=5`, `0x0c[3]=0` plus toggling GPIO 48.)
   - format/clock/TDM fn `0x82a0a8c` (see 1.4).
   - per channel: `0x0b = cfg[1]&0x3f = 0x2b` (full write; overwrites the bit6 set in 1.4), `0x0c[1:0] = cfg[2] = 0x02` (mask 0x03).
2. `writeAll(0x06, 0x80)` — PWRCTL1: chip up, boost on (PDN_BST=0), amp still off (PDN_AMP=1).
3. `0x82a2e5c(2)` per channel: `0x07 = pwrctl2(slots)` (`0x82a31ec`, see 1.5); `0x08[7:6]=0x40` (mask 0xc0: MCLKDIS=0, DIV2=1);
   `0x09 = cfg[0] = 0xaa`; `0x10 = 0x19` (DIG_VOL = mute code); `0x0f[4] = 0` (mask 0x10, DIGSFT off); `0x11 = 0x1c`; `0x0e = (rd & ~0xcf)|0xc4`;
   `0x12[7:4] = cfg[3] = 0x70` (mask 0xf0 -> gain code 7); `0x3a = cfg[0xc] = 0x8a`, `0x3b = cfg[0xd] = 0x10`, `0x3c = cfg[0xe] = 0x73`, `0x3d = cfg[0xf] = 0x03`
   (if `speaker-vbca` existed, 0x3a would instead be its derived byte).
4. wait 10 ms.
5. alive watchdog off again (`0x82a13e4(0)`, same 2 writes).
6. `writeAll(0x06, 0x00)` — amp + boost + all powered.
7. wait 8 ms.
8. `0x82a3260` per channel (protection/Class-H config): read `0x15` twice, `0x16` twice (clear latched status);
   `0x17=0x5a; 0x18=cfg[0x13]=0x40; 0x17=0x00` (diag unlock/write/lock — 0x40 is the default, a no-op);
   `0x23[6:0]=cfg[4]=0x6a`; `0x24=cfg[5]=0x80`; `0x25[4:2]=cfg[6]&0x1c=0x10`; `0x26=cfg[7]=0x1e` (default); `0x27[5:0]=cfg[8]=0x02` (default); `0x28=cfg[9]=0x04` (default);
   `0x29[6:0]=cfg[10]=0x14`; `0x2a[7,4:0]=cfg[11]=0x89` (mask 0x9f); `0x11=0x14` (AMP_CAL bit cleared; AMP_DRV_SEL stays 1).
9. After any change to non-zero state the framework calls `0x82a1e98` (volume): `writeAll(0x10, v)`;
   `v = 0x19` when property 0x130 or 0x12f is set (mute flags) **[M]**, else `0x34 + vol(prop 0x131)` — i.e. 0x19..0x33 = mute, 0x34..0xFF = -102 dB..-0.5 dB (matches the `SX_TLV 0x34,0xE4` control in cs35l33.c) **[M]**.

Other transitions (same register vocabulary): 0→1 = `2ce8(1)`, `3570`, `2e5c(1)`, `3260`; 1→2 = `2030(1)`, `0xa8c`, `0x06=0x80`, `0x08[7:6]=0x40`, 10 ms, `0x07=pwrctl2` per ch, alive, `0x06=0x00`, 8 ms, read 0x15/0x16 x2.
`3570` (PWRCTL1 standby) = `0x06 = 0x84` if "master" amp (`0x82a1354` true) else `0x06 = 0x85` + 4 ms **[M]**. `2e5c(1)` = `0x07=0xfc` then `0x08[7:6]` = 0x40 (master) / `0x08[7]=0x80` (non-master) + the same cfg writes as step 3.

### 1.4 Format / sample rate / TDM slots (`0x82a0a8c`, per channel) **[H]**, semantics **[M]**
Struct from `0x82a0ee0(mode=2 "ext")`: rate (Q32.32 Hz, 48 kHz = 0xbb80<<32 on n61), bytes per slot (16-bit slots → 2, from `vt+0x810>>3`), slot indices for the 5 monitor streams (`spV`,`spI`,`spP`,`spB`,`spF` = VMON, IMON, VPMON, VBSTMON, FLAG) and for the 3 inbound streams (`spA` audio, `spK` alive, `spS` supply), looked up from the "ext" data-source/slot-mask info.
1. `0x0d = 0x03` (ADSP_CTL: slave, ALIVE_RATE=3; "master" amp would get `0x43`). **[M]** (not ext master)
2. `0x08 = fscode`: `0x40 | code`; code table (MCLK 12.000 MHz after DIV2):
   48k=0x09, 44.1k=0x0b, 32k=0x0d, 24k=0x11, 22.05k=0x13, 16k=0x15, 12k=0x19, 11.025k=0x1b, 8k=0x1d; any other rate -> plain 0x40. (L19 default 0x0b = "44.1 kHz class, MCLK enabled".)
3. Monitor TX position regs via helper `0x82a127c(chan,reg,slot,bytes)`: value = `(slot-1)*bytes`, or **0x80** if slot==0 (disabled): `0x2d`=VMON, `0x2e`=IMON, `0x2f`=VPMON, `0x30`=VBSTMON, `0x31`=FLAG. The helper returns a byte-enable mask `((1<<bytes)-1)<<pos`; ORed together and written as TX_EN: `0x32 = mask>>24`, `0x33 = >>16`, `0x34 = >>8`, `0x35 = &0xff`.
4. `0x36` RX_AUD: if audio slot != 0: `((bytes<<5)+0xe0 | (slot-1)*bytes) & 0xff` = `((bytes-1)<<5) | loc` (16-bit, slot 1 -> **0x20**), else `0xc0`. `0x38` RX_ALIVE and `0x37` RX_SPLY via the helper (0x80 when absent).
5. `0x0b[6] = 0x40` if supply slot present else 0; `0x0c[4] = 0x10` if alive slot present else 0 (both then overwritten/merged by 1.3 step 1).
Exact slot numbers for n61 depend on runtime data from the MCA `audio-speaker` node (TX slot mask 0x1, RX slot mask 0xf) — **[L]** for the monitor slots; the audio slot is surely slot 0 -> byte 0.

### 1.5 PWRCTL2 (`0x82a31ec`) **[M]**
Starts all-powered-down for unused monitors: bit7=VMON unused, bit6=IMON unused, bit5=VPMON unused, bit4=VBSTMON unused, bit3 (SDOUT 3-state) set when no monitor stream is routed; bit2 (PDN_SDIN) and bit1 (PDN_TDM) always 0 while playing.
No monitors routed -> **0xf8**. Standby/stop writes: `0xfc` (SDIN off) on 2→1 and 1-state config; `0xfe` at full shutdown.

### 1.6 Stop / power-down
- 2→1 (`0x82a2a60`): `3570` (`0x06=0x84/0x85`), alive off, `writeAll(0x07,0xfc)`, per ch `0x08[7:6]=0x40`(master)/`0x80`(non-master, ch0 also MCLK off).
- 2→0 / 1→0 (`0x82a2a04`/`0x82a29a8` -> `0x82a36c0`): `writeAll(0x10,0x19)` (mute), `updateAll(0x06, 0x80, 0x80)` (PDN_AMP), `writeAll(0x07,0xfe)`, 1 ms, `writeAll(0x06,0x87)`, 4 ms, `setReset(1)` (GPIO 49 low), MCLK off.

### 1.7 Calibration / speaker protection
- No register writes use `speaker-calib` (`SpCl`, 12 B), `speaker-rdc` (`SRdc`, 4 B) or `at-scale`: they are only parsed into the framework object `this+0x178` / `this+0x210/0x218` and served to the host speaker-protection code through properties 0x14f..0x15e, 0x1b6, 0x171 (`0x82a19a0`, `0x82a19e4`, `0x82a1b88`) **[M-H]**. Apple's protection (Rdc/excursion limiter) runs on the host/AOP side; the chip has no DSP.
- On-chip "calibration" = AMP_CAL: `0x11 = 0x1c` before amp power-up (bit3=1), `0x11 = 0x14` after (step 8) **[H]**.
- Hardware protections kept: boost UVLO/ipk (`0x09=0xaa`), class H/G (0x23..0x2a). INT masks (0x13/0x14) never written by iOS (default 0xff); status read (0x15/0x16 twice) only.

### 1.8 `speaker-config` decode (20 B `aa 2b 02 70 6a 80 30 1e 02 04 14 89 8a 10 73 03 05 d0 04 40`, per amp)
| idx | val | -> reg | meaning |
|---|---|---|---|
| 0 | aa | 0x09 | boost peak current (L33 formula `1.85 A + (v-0x70)*15.625 mA` = 2.76 A, **[L]** on L19) |
| 1 | 2b | 0x0b & 0x3f | boost voltage code 43 (L33 binding: 3.3 V + (n-1)*0.1 V = 7.5 V) |
| 2 | 02 | 0x0c[1:0] | VBST slew step |
| 3 | 70 | 0x12[7:4] | amp gain 7 |
| 4..11 | 6a 80 30 1e 02 04 14 89 | 0x23 0x24 0x25 0x26 0x27 0x28 0x29 0x2a | class H/G: mem depth 3 (16), ldo_thld 5, release rate 0x80, ldo entry delay 4, hd_rm 0x14, hg en + vp_hg 9 |
| 12..15 | 8a 10 73 03 | 0x3a..0x3d | boost-loop coefficients (L19 only; defaults 06 32 74 03) |
| 16 | 05 | 0x46 | trim |
| 17 | d0 | 0x66 | trim |
| 18 | 04 | 0x54 | trim |
| 19 | 40 | 0x18 | diag ctrl (= default) |

## 3. Minimum "get sound out" sequence (phone, bus 1, addr 0x40, MCA2 already clocking I2S 48 kHz / 16x8 slots)
Assumes MCLK pin = 12.000 MHz (open question: MCA-V1.md derives 12.288 MHz for the NCO; the kext demands exactly 12 MHz. If chip flags MCLK_ERR in 0x15 bit3 after power-up, measure the real MCLK).
Values are final register values, pre-computed from the dump defaults (tools/i2c has no read-modify-write).
```
tools/gpio 49=1 ; sleep ~20 ms          # release reset; check: tools/i2c 1 40 r 01 -> 35 a1 90
# rev-B0 trim (iOS 1.2); 00 99 unlocks, 00 00 locks
tools/i2c 1 40 w 00 99 w 45 3f w 46 05 w 51 ff w 59 0a w 6b 20 w 54 04 w 00 00
tools/i2c 1 40 w 00 99 w 66 d0 w 00 00
# alive watchdog off, serial port, clock, slots
tools/i2c 1 40 w 0a 58 w 0c 0a w 0d 03 w 08 49 w 0b 2b
tools/i2c 1 40 w 2d 80 w 2e 80 w 2f 80 w 30 80 w 31 80 w 32 00 w 33 00 w 34 00 w 35 00
tools/i2c 1 40 w 36 20 w 37 80 w 38 80        # audio in byte 0, 16-bit; no VP/alive slots
# power: chip+boost, configure, then amp
tools/i2c 1 40 w 10 19 w 06 80
tools/i2c 1 40 w 07 f8 w 09 aa w 0f 04 w 11 1c w 0e c4 w 12 70 w 3a 8a w 3b 10 w 3c 73 w 3d 03
tools/i2c 1 40 s 10 w 06 00 s 8
tools/i2c 1 40 r 15 r 15 r 16 r 16               # clear latched status; then read 15/16 again, expect 0
tools/i2c 1 40 w 17 5a w 18 40 w 17 00 w 23 6a w 24 80 w 25 30 w 29 14 w 2a 89 w 11 14
# unmute at -20 dB (0xd8 = (0xd8-0x100)/2 dB); 0x19 = mute, 0x00 = 0 dB (loud)
tools/i2c 1 40 w 10 d8
```
Power-down: `w 10 19 w 06 80 w 07 fe s 1 w 06 87 s 4`, then `tools/gpio 49=0`.
Checks: after `w 06 00` read 0x15/0x16 (bit6 CAL_ERR, bit2 AMP_SHORT, bit1/0 OTW/OTE, bit3 MCLK_ERR, bit4 ADSPCLK_ERR). If no sound but no flags, the MCA2 slot/format (frame pulse polarity, 8x16 vs the amp's RX_AUD loc) is the suspect; try `w 36 20` vs `w 36 40` (loc 2). If MCLK_ERR, drop the DIV2/12 MHz assumption: try `w 08 09`/`w 08 19` (no DIV2) and scan fs codes.

## 4. Patch plan for sound/soc/codecs/cs35l33.c
1. Chip info struct (`struct cs35l33_chip`): `devid`, `reg_defaults`, `patch`, `clk coeff table`, `max_register`, flag `is_l19`. `of_device_id`: add `{ .compatible = "cirrus,cs35l19", .data = &cs35l19_chip }` and `i2c_device_id "cs35l19"`; replace the hard `devid != CS35L33_CHIP_ID` check with `devid == chip->devid` (`CS35L19_CHIP_ID 0x00035A19`; `cirrus_read_device_id()` already yields it); log revision.
2. regmap: `cs35l19_reg[]` = `cs35l33_reg[]` with 0x08=0x0b, 0x09=0x40, 0x0e=0x07, 0x24=0x01, 0x25=0x30, 0x39=0x00, plus 0x3a..0x3d (06 32 74 03). `max_register` 0x6f; add 0x3a..0x3d (+0x45,0x46,0x51,0x54,0x59,0x66,0x6b) to readable/writeable; volatile unchanged (0x15/0x16). Use the dump file for a regcache sanity check (`regcache_sync` must not touch trim page).
3. Probe patch: for L19 apply `{0x00,0x99},{0x45,0x3f},{0x46,v46},{0x51,0xff},{0x59,0x0a},{0x6b,0x20},{0x54,v54},{0x00,0x00},{0x00,0x99},{0x66,v66},{0x00,0x00}` **instead of** `cs35l33_patch` (it writes 0x39=0x45 etc. which iOS never does on L19). v46/v54/v66 default to 0x05/0x04/0xd0 and are overridable by DT.
4. Clocking: L19 table (`mclk_int` after DIV2 = 6 MHz): `{8000:0x1d,11025:0x1b,12000:0x19,16000:0x15,22050:0x13,24000:0x11,32000:0x0d,44100:0x0b,48000:0x09}`; `hw_params` writes `update_bits(CLK_CTL, 0x5f, 0x40|code)` (DIV2 + code) for L19 instead of `ADSP_FS|INT_FS_RATE`. Add `set_sysclk` support for 12 000 000 (`CS35L33_MCLK_12` exists) -> mclk_int 6 MHz + DIV2 bit.
5. Keep TDM path: `is_tdm_mode` true, `set_tdm_slot(tx_mask=monitor slots, rx_mask=BIT(0), slots=16, slot_width=8)` (byte positions); RX depth from `params_width` already gives 0x20 for S16_LE. iOS always runs PDN_TDM=0 + SDIN on; monitors off = PWRCTL2 0xf8 (3-state bit3, mapped by `sdout_event`).
6. Power sequence (replace L33 DAPM order for L19): MCLK on -> reset release -> patch -> alive-WD off -> clock/slots -> `PWRCTL1=0x80` (boost on) -> config -> 10 ms -> `PWRCTL1=0x00` -> 8 ms -> `AMP_CAL` flow: `CLASSD=0x1c` before / `0x14` after (instead of cs35l33.c's "set CAL after power-up + 10 ms"); on shutdown mute (`DIG_VOL=0x19`), `PWRCTL1 |= 0x80`, `PWRCTL2=0xfe`, 1 ms, `PWRCTL1=0x87`, 4 ms, reset low.
7. Alive watchdog: `PROTECT_CTL[3:0]=8` and `BST_CTL2[3]=1` (current probe uses mask 0x0c only) so GPIO 48 (`function-alive`) is not needed.
8. DT / properties: existing `cirrus,boost-ctl = <43>`, `cirrus,boost-ipk` (L33 µA formula, or new raw `cirrus,boost-ipk-raw = <0xaa>`), `cirrus,imon-adc-scale = <4>` (extend the allowed list for L19), `cirrus,hg-algo { mem-depth=<3>; release-rate=<128>; hd-rm=<20>; ldo-thld=<5>; ldo-entry-delay=<4>; vp-hg=<9>; }`. New (L19 only): `cirrus,amp-gain = <7>` (reg 0x12[7:4]), `cirrus,boost-coeff = /bits/ 8 <0x8a 0x10 0x73 0x03>` (0x3a..0x3d), `cirrus,trim = /bits/ 8 <0x05 0x04 0xd0>` (0x46, 0x54, 0x66). Alternatively one 20-byte `cirrus,speaker-config` blob copied verbatim from Apple's DT.
9. Board DT (t7000-n61.dts, `&i2c1`): `speaker-amp@40 { compatible = "cirrus,cs35l19"; reg = <0x40>; reset-gpios = <&pinctrl 49 GPIO_ACTIVE_HIGH>; interrupts-extended = <&pinctrl 47 IRQ_TYPE_LEVEL_LOW>; VA-supply/VP-supply = fixed/dummy (driver requires both); sound-name-prefix "Speaker"; }`. Interrupt polarity from Apple's `[47 1]` is unverified **[L]**; `devm_regulator_bulk_get` needs dummy supplies.
10. Machine side (outside this file): MCA2 DAI link to this codec, 48 kHz, 8x16 TDM, BCLK 6.144 MHz, TX slot 0, MCLK 12 MHz source.
